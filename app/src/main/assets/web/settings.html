レイアウト・配色

ダッシュボード全体の並びと色を決めます。カードごとの表示・非表示は左のメニューの各カードにあります。

主要なカードの幅の配分が変わります。
カードを非表示にしても空白は残りません。空いた列は同じ行に残ったカードへ自動で配分され、 1 行が常に画面幅いっぱいになります。

画面の明るさ

壁掛けでは端末の自動輝度が明滅するため、明るさはアプリ側で固定します。

操作があるときの画面の明るさです。
画面に触れると即座に元の明るさへ戻ります。CSS で暗く見せるのではなく バックライト自体を下げるため、消費電力と焼き付きの両方に効きます。
有機 EL や一部の液晶では、同じ位置に同じ絵を長時間映し続けるとその形が薄く残ることがあります （時計の数字や枠線など、動かない部分ほど起きやすい）。 これを避けるため、5 分ごとに画面全体を上下左右へ最大 2 ピクセルだけゆっくり動かします。

場所

天気・時間別予報・週間予報・日の出入りが、ここで決めた地点のものになります。

Open-Meteo の地名検索はローマ字か英語で入力してください（「札幌」では一致しません）。結果は日本語で返ります。

時刻

大きな時計と日付を出すカードです。

天気

現在の気温・体感・降水確率・UV・AQI などを出すカードです。

時間別予報・週間予報の気温にも同じ単位が使われます。
気温と天気概況は常に出ます。ここで選ぶのはその下に並ぶ数値です。 3 列で折り返すので、9 項目だとちょうど 3 行に収まります。 すべて外した場合は既定の 9 項目に戻ります。
観測地点は「場所」で設定します（現在: —）。 データは Open-Meteo から取得しており、API キーは不要です。

防災（気象庁）

警報・注意報、地震、津波、台風、噴火を出すカードです。右側には強震モニタを重ねます。

切ると通信自体を止めます。カードを隠すだけなら上の「表示する」を外してください。
この震度以上で直近の 1 件だけを表示します。
津波と警報・注意報は命に関わるため、常に表示します。
強震モニタを外すと本文が横いっぱいに広がり、3 秒ごとの画像取得も止まります。
気象庁は警報の種別コードの名称テーブルを公開していません。誤った種別名を壁に出さないため、 種別名は表示せず、気象庁が発表した本文と、発表中の地域名を表示します。
カード右側の強震モニタ（防災科研・いま揺れている観測点）は 3 秒ごとに更新され、設定は不要です。

LINE メモ

LINE に送った文章を壁に出すカードです。新しい順に並び、カード内をスクロールできます。

切ると中継先へのポーリングを止めます。
Worker の URL を貼ってください。末尾のパスは自動で /memo に直します。 LINE 側に登録する /line/webhook とは別の入口なので、間違えても補正されます。
Worker に DEVICE_TOKEN として設定したものと同じ値を入れてください。保存後は読み出せません。
LINE は公開された HTTPS の Webhook にしかメッセージを届けません。このタブレットは家庭内 NAT の内側にあり、 既定では loopback しか待ち受けないため、中継サーバー（Cloudflare Worker）を経由します。 タブレットは中継先に外向きにポーリングするだけで、インターネットからの着信は一切受けません。 セットアップ手順は worker/README.md を参照してください。

時間別予報

これから 12 時間の気温と降水確率を折れ線と棒で出すカードです。

降水確率だけにすると、棒がカードの高さいっぱいまで伸びます。
地点は「場所」、気温の単位は「天気」の設定に従います。

Spotify

再生中の曲のジャケットと曲名を出し、再生・一時停止・曲送りができるカードです。

どちらも外すと、空いた高さをジャケット・曲名・アーティスト名に回して大きく表示します。
秘密の値ではありません。保存してから「Spotify と連携」を押してください。
操作は Spotify で鳴らしている端末に送るもので、このタブレットからは音は出ません （曲送りには Spotify Premium が必要です）。履歴・ライブラリ・プレイリストには触りません。
使うには Spotify のアプリ登録が必要です: Spotify Developer Dashboard で「Create app」→ Redirect URI に http://127.0.0.1:8080/api/spotify/callback を追加 → API は「Web API」を選択。 できた Client ID を上に貼ってください（Client Secret は使いません）。

Wi-Fi

リンク速度・SSID・電波強度・実際に流れている通信量を出すカードです。

外すと、その幅ぶん速度と SSID の列が広がります。
表示している速度は Wi-Fi の物理リンクレートで、インターネットの実効速度ではありません。 SSID が出ない場合はカード内にその理由が表示されます（位置情報の権限など）。

端末状態

CPU 使用率・バッテリー・温度・ストレージ・メモリを出すカードです。

値はすべて端末内から読んでいます。CPU 使用率は cpuidle を読めない端末では表示されません。

ニュース / RSS

登録したフィードの見出しを出すカードです。カード内はスクロールできます。

切ると取得自体を止めます。
RSS 2.0 と Atom に対応しています。
サイトのトップページ URL を入れた場合は、ページ内の RSS リンクを自動で探します。 見つからない場合はフィードの URL を直接指定してください。
例: https://gigazine.net/news/rss_2.0/ ／ https://news.yahoo.co.jp/rss/topics/top-picks.xml

週間予報

向こう 1 週間の最低・最高気温、降水量、降水確率を出すカードです。

地点は「場所」、気温の単位は「天気」の設定に従います。このカード固有の設定はありません。

タイマー

時・分を指定して鳴らすカードです。設定した残り時間は端末内に保存され、再読込しても続きます。

鳴動音はブラウザ内で合成しています。音量は端末のメディア音量に従います。

今日の単語

英検準 1 級レベルの単語を 1 時間に 1 語出すカードです。

辞書はアプリに同梱しているため、通信が切れても空欄になりません。

ハムスター

画面の下で回し車を走るハムスターです。カードではないので、並びには影響しません。

走る・休む・外を歩く・立ち止まる、の 4 つを順に繰り返します。 非表示にすると動きの処理も止まるため、わずかですが消費電力が下がります。
意匠は Uiverse.io の Nawsome 作「Loader」(MIT License) によります。

ホームアプリ

再起動したあと、ダッシュボードを自動で前面に戻すための設定です。

Android 10 以降はバックグラウンドからの画面起動が制限されるため、再起動後にダッシュボードが 自動で前面に出るとは限りません。この端末のホームアプリを Walldash にすると確実に前面へ戻ります。 有効化したあと、端末側で「ホームアプリ」の選択ダイアログが出たら Walldash を選んでください。 無効のままだと、再起動のたびに手動でアプリを開く必要があります（サービス自体は約 90 秒で自動復帰します）。

ネットワーク（LAN 公開）

既定ではこの端末の中（127.0.0.1）からしか設定画面を開けません。LAN の他の端末からも開けるようにします。

LAN 公開は家庭内の信頼できる LAN 限定の機能です。通信は平文 HTTP のため、 ログイン PIN やセッションは同一ネットワーク上で盗聴され得ます。 ゲスト Wi-Fi、社内共有 LAN、不特定多数が接続するネットワークでは有効にせず、 USB 接続（adb forward 経由の localhost）からの設定のみを使ってください。
